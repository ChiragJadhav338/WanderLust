🌍 WanderLust – Travel Listing & Accommodation Platform
📌 Project Overview

WanderLust is a full-stack web application that allows users to explore, list, and manage travel accommodations from different locations.
The platform is inspired by modern travel marketplaces and provides an easy way for users to discover places, add listings, and share travel experiences.

🚀 Features
🏠 Listing Management

View all travel listings

Add new accommodation listings

Edit existing listings

Delete listings

View detailed information about each listing

👤 User Features

User registration and login

Secure authentication

Personalized user sessions

⭐ Reviews & Ratings

Add reviews for listings

View reviews from other users

Delete reviews

🗺 Location & Travel Experience

Explore accommodations from different locations

Travel-friendly interface for browsing destinations
